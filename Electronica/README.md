# Electronica
Relación de sensores, actuadores, y cableado necesario para el proyecto

# Sensores
- Sensor de distancia infrarrojos: hay que seleccionar el sensor y diseñar brick
- Sensor distancia ultrasonidos; hay que seleccionar el sensor y hacer brick
- Sensor de humedad tierra: seleccionar sensor y brick

# Actuadores
- 3 LEDS "gordos" hay que diseñar brick

# Cableado
- 9 Pinza cocodrilo
- 5 conectores hembra-hembra 

# Motores
Incluidos en laas piezas Lego
- 2 servocontinuos de posicion
- 2 servos continuos
