# Estatuas musicales

![portada](https://github.com/lobotic/Proyectitos/blob/master/Echidna/Juego_de_las_estatuas/juegoestatuasportada.png)

## Descripción
Este segundo proyecto con bloques de construcción combina juego, mecánica y programación para crear un sistema inspirado en Dancing Birds de LEGO WeDo. En esta versión, unos patos se mueven gracias a un motor de corriente continua y un sencillo sistema de poleas con banda de goma, reaccionando al sonido como en el juego de las estatuas musicales.
El modelo está controlado por una EchidnaBlack2 programada con EchidnaML, utilizando el micrófono integrado para detectar música o ruido. Cuando el sonido supera un umbral, el motor se activa y los patos “bailan”; cuando el sonido desaparece, se detienen. Un pequeño retardo en la programación suaviza el movimiento y mantiene el ritmo.
El proyecto incluye además una guía de construcción paso a paso creada con LeoCAD y LPub3D, facilitando que cualquiera pueda montarlo y adaptarlo.
